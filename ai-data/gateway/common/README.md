# gw_common

Shared metrics (AUROC, AP, Brier, ECE, Platt, block bootstrap), numpy GRU, numpy message passing, synthetic weather generator, generic PyTorch GRU trainer (`train_gru.py`, imports torch lazily). See [`FICHE.md`](FICHE.md). Tests: `cd python && PYTHONPATH=src python -m pytest tests -q`.
