# tests/data

`real_bme688_sample.npz`: 1798 scans (6 files/sensors) from "Dataset Smoke Detection", Matteo Anedda,
University of Cagliari, Mendeley Data, DOI 10.17632/48j7mm8k56.1, licence CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).
Changes: only a subset of scans kept; rows regrouped into complete 10-step scans; the 7 burn phases renumbered by order.
Units in this file: gas in ohm, temp and rh multiplied by 100. Burns: 2021 (node 1) and 2025 (nodes 2 to 5).
